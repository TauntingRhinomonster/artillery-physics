# Artillery Physics

An interactive web app where a user inputs an angle and power, and the application calculates and animates the trajectory of a projectile to hit a target.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Download vite TypeScript Vanilla
2. Clone the repository
3. Open your command line and type `npm run dev` then press enter.

Instructions for using the software:

1. There are inputs which allow the user to change several different settings in regard to the artillery's flight.
2. Enter in values of your choice.
3. Press "Fire" to watch the artillery's trajectory.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* NPM 10.9.2
* Vite version 8.0.14
* TypeScript version 6.0.3
